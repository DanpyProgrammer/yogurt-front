# Catálogo de álbumes

Aplicación web desarrollada con TypeScript y Vite que consulta los álbumes de JSONPlaceholder y los muestra en una tabla.

## Requisitos

- Node.js
- pnpm

## Instalación y ejecución

```bash
pnpm install
pnpm dev
```

Abre en el navegador la dirección que indique Vite en la terminal.

## Compilar para producción

```bash
pnpm build
```
